// BACKGROUND

Who's building this

I'm a full-stack Java developer currently working on enterprise systems at LTIMindtree, where I build and maintain REST APIs on Spring Boot and PostgreSQL, ship Angular UI modules, and run CI/CD pipelines through Jenkins for production deployments.

Outside client work, I build things end-to-end to keep my architecture instincts sharp — GymAI, a microservices-based fitness platform with an AI recommendation service, event-driven progress tracking over Kafka, and a self-hosted deployment on a Raspberry Pi cloud server; and a car rental platform with booking, payments, and vehicle-availability services wired together over ActiveMQ. Both taught me more about what breaks in production than any tutorial could.

I hold an MCA from Lovely Professional University and a BCA from Rajasthan University, and I'm an Oracle Certified Java Programmer. Neelastack exists because I'd rather build a handful of things properly for people who need them done right, than a lot of things quickly for people who won't notice the difference until it's too late.
